## Data Safety（如实勾选）

### 数据收集概览

| 类型 | 是否收集 | 说明 |
|------|----------|------|
| 姓名、邮箱等个人身份 | 否 | 无自有账号 |
| 财务信息 | 否 | |
| 位置 | 否 | |
| 应用活动（成就/排行） | 是（可选） | 仅当用户连接 Play Games，由 Google 处理 |
| 应用信息与性能 | 可能 | AdMob 崩溃/诊断（Google 政策） |
| 设备或其他 ID | 是 | 广告 ID（AdMob，需 UMP 同意） |
| 用户内容 | 否 | 存档仅本地 |

### 数据用途

- 应用功能：本地存档
- 广告：AdMob 展示广告
- 分析：依赖 Google/AdMob 默认（按 Console 问卷逐项选）

### 数据是否加密传输

- 是（HTTPS，广告与 Play 服务经 Google）

### 用户能否请求删除

- 本地数据：清除应用数据 / 卸载
- Play Games：Google 账号设置
- 联系开发者：beatinghousehunan@gmail.com

### 数据是否共享给第三方

- 是：Google（AdMob、Play Games）
