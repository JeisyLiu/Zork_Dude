# 内部测试验收清单

上传 `app-release.aab` 到 Internal testing 后，用测试账号逐项勾选。

## 安装

- [ ] 测试人员已加入 Internal testing 名单
- [ ] 通过 Play 商店测试链接安装（非 sideload APK）
- [ ] 首次启动无崩溃

## 探索与存档

- [ ] 新游戏可进入探索界面
- [ ] 移动、背包、地图正常
- [ ] 存档槽读写正常
- [ ] 继续旅程可恢复进度

## Play Games

- [ ] 主页「成就」「排行榜」可点击
- [ ] 静默登录或连接提示正常
- [ ] 离开森林入口触发「雾中苏醒」类成就（Console 可能有延迟）
- [ ] 战斗胜利后成就/排行榜 Outbox 补推无报错

## 广告与隐私

- [ ] 首次启动 UMP 同意流程（如适用地区）
- [ ] 设置中隐私入口可打开
- [ ] 激励广告位可加载（测试设备 ID 已配置时）

## 多语言（抽检）

- [ ] 系统英语：UI 与探索文案为英文
- [ ] 系统简体中文：UI 与探索文案为中文

cd flutter_app
flutter build appbundle --release
# 产物：build/app/outputs/bundle/release/app-release.aab
